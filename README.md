# Kyomei

Premium bilingual website for a Japanese music marketing agency focused on short-form discovery campaigns.

## Overview

Kyomei is a polished marketing site for helping artists, labels, and music teams turn one song into many short-form video moments across Japanese-facing social platforms. The site is designed to work in both English and Japanese, with Japanese copy written to feel natural for local readers rather than translated word-for-word.

## Highlights

- Bilingual English/Japanese experience
- Campaign offer sections for short-form music discovery
- Contact form routed to the business inbox
- SEO metadata and social preview image
- Cloudflare Pages static build support
- Responsive layout tuned for large hero typography in both languages

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vinext / OpenAI Sites tooling
- Cloudflare Pages static export script

## Local Development

```bash
npm install
npm run dev
```

## Cloudflare Pages Build

```bash
npm run build:cloudflare
```

Build output directory:

